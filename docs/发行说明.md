## 手动验收路线

1. 用六种机体分别开局，检查操作手感、自动拾取、闪避无敌、护盾和超载。
2. 标准与挑战难度各完成一次，验证 5/10/15/20 波首领阶段转变。
3. 在第 2 波关闭程序，重新打开，“继续游戏”应从第 2 波开头恢复。
4. 通关或失败后购买永久升级，再开局检查基础属性变化。
5. 调低音量，关闭音乐与音效；测试没有音频设备时仍可玩。
6. 战斗中切到其他窗口，应自动暂停；测试退出键、P、点击暂停和菜单制表键操作。
7. 改变窗口大小，确认黑边、鼠标瞄准和菜单点击坐标一致。
8. 将完整便携文件夹复制到没有 JDK 的 Windows x64 电脑验证启动。
