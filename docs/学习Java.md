# 从这款游戏学习 Java

先运行游戏，再读代码。不要一开始同时研究所有类。

## 第一天：入口、变量、对象

打开 `Main.main()`：SwingUtilities.invokeLater 把窗口创建放到 Swing 事件线程。`new JFrame(...)` 创建窗口，`new GamePanel(...)` 创建能接收输入和绘图的面板。

打开 `GameModel.Player`：`double hp` 是可变生命值，`maxHp` 是上限，`x/y` 是位置。`GameModel` 持有一个 Player，所以用 `model.player.hp` 访问它。这种把对象放进另一个对象的方式叫组合。

练习：把 `Loadout.STRIKER` 的初始生命从 100 改成 120，运行新局观察数字变化。改完再恢复。

## 第二天：枚举和控制流程

`Screen` 枚举表示主菜单、战斗、暂停、升级、结算等状态。`GameRenderer.render()` 用 switch 决定画哪个界面；`GameModel.update()` 只在 PLAYING 状态更新战斗，因此暂停不会继续扣血。

`Loadout` 枚举把六种机体的名字与基础属性放在一起；`Upgrade` 枚举给每种强化一个明确的标识，比散落的字符串更不容易拼错。2.0 还加入了护盾、超载、连击、无人机和精英敌人，可以继续观察这些状态如何在同一套 `GameModel.update()` 循环里组合。

练习：在 `GameModel.hurt()` 放断点。撞敌人后观察 `damage`、`hp` 和 `invincible`，用 Step Over 看单行执行效果。

## 第三天：游戏循环与向量

`GamePanel` 的 Timer 大约每 16 毫秒回调一次，计算距离上次回调的秒数 dt，再调用 update。移动的公式是 `位置 += 速度 × dt`，所以不是“每帧移动固定距离”。窗口卡顿时 dt 被限制到 0.05，避免巨大时间跨度导致穿墙。

同时按 D、S 的方向是 (1,1)。如果直接使用它，斜向长度为根号 2，会比直线快。代码除以 `Math.hypot(dx,dy)` 将方向归一化，速度就一致。

练习：把 player.speed 临时减半，看移动是否减慢；用调试器验证不同 dt 下的位移。

## 第四天：子弹、集合、碰撞

`enemies` 和 `bullets` 是 ArrayList。每帧遍历对象更新位置，然后移除死亡对象。需要边遍历边删除的地方使用 Iterator；先标记 life=0 再 removeIf，也能避免遍历时直接修改集合引起异常。

高速子弹一帧可能越过敌人，不能只测子弹最后位置。`segmentDistance()` 测量敌人中心到子弹上一位置与当前位置线段的最短距离，这叫连续或扫掠碰撞。

穿透弹用 `Set<Long>` 记录已经命中的敌人 id，避免子弹停留在敌人体内时连续伤害同一个对象。

练习：运行 GameTests，在 collision() 里改子弹速度，观察高速命中仍然通过。再尝试自己写一个“子弹没经过敌人”的测试。

## 第五天：存档与异常

Properties 是 Java 自带的键值配置格式，可以打开 data 中的文件阅读。SaveStore 从磁盘读取，校验版本，再把文本转换成数值；未知数值给默认值并限制范围，避免坏数据影响程序。

保存时先写 `.tmp`，强制刷新到磁盘，再用原子移动替换正式文件。旧档复制到 `.bak`。文件权限不够或磁盘不可写会抛 IOException，面板把它显示成提示，并稍后重试。

练习：复制 data 为备份，关闭游戏，然后修改信用点重新打开。再把主存档内容改坏，观察备份恢复。不要在游戏运行时编辑它。

## 第六天：绘图与线程

所有界面以 1280×800 虚拟坐标绘制。窗口缩放只改变绘图变换；鼠标坐标反向转换回虚拟坐标，游戏逻辑仍使用同一坐标系。

窗口、输入、游戏规则都在事件线程上运行，避免同步争用。音频单独使用守护线程，因为播放音频会阻塞。Settings 中被两个线程读写的字段使用 volatile，音效事件通过有界队列传递。

练习：把 GameRenderer.CYAN 的颜色改成另一种色调。保持玩法不变，你就完成了一个主题变体。

## 后续挑战

- 新增一种敌人：在 EnemyType、Enemy 构造逻辑、updateEnemies、enemy 渲染和测试中添加它。
- 给波次增加章节配置：把 quota、敌人比例和 Boss 属性抽成不可变记录。
- 新增强化：扩展 Upgrade 和 applyStats，然后增加检查点恢复测试。
- 本地化：把现有中文文案抽成资源键，使用 ResourceBundle 支持多语言切换。
- 给敌人生成加入空间网格：比较大量对象时的碰撞效率。

每次只改一种功能，运行构建与测试，再实际试玩。自动测试能发现规则错误，但玩家手感必须靠试玩判断。
