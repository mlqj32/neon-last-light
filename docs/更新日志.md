# 更新日志

## 2.0.0 · 远征版（2026-11-22）

### 战役与敌人

- 战役从 12 区扩展到 20 区。
- 首领改为第 5、10、15、20 区，共四名：哨卫·棱镜、先知·零、织网者·弥撒、终末守望者。
- 新增编织者、哨戒机、巢母三种敌人，分别负责横向弹幕、护盾防守和召唤小怪。
- 新增精英敌人：金色外环，生命、速度、掉落更高。
- 新增蜂群警报、精英猎杀、离子风暴三种波次修正。

### 机体与成长

- 新增长枪、新星、神盾三种机体，总机体数达到六种。
- 新增暴击、链式电弧、追踪弹、相位护盾、吸血纳米、护卫无人机、反应装甲七种强化。
- 新增护盾层数、超载槽、连击倍率、完美区域奖励和护盾/超载掉落。
- 无人机自动索敌射击；链式电弧可在敌群中跳跃；暴击与吸血改变输出节奏。
- 结算增加完美区域、最高连击和首领击杀奖励。

### 界面与文档

- 主菜单改为六机体两行卡片布局。
- HUD 增加护盾槽、超载槽、连击和波次修正提示。
- 飞行手册扩充到八类敌人、四名首领和完整掉落说明。
- README 与 `docs/screenshots/` 增加主菜单、战斗、强化、手册、工坊、结算、设置、暂停截图。
- 构建版本更新为 `neon-last-light-2.0.0.jar`。

### 验证

- `GameTests`：165 条断言通过。
- 六种机体均在休闲难度自动战斗完成 20 区。
- 九种中文界面离屏渲染通过。
